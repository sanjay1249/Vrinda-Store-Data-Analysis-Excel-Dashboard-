# 📊 Vrinda Store Data Analysis (Excel Dashboard)

## 📌 Project Overview
This project focuses on analyzing sales data from Vrinda Store using Microsoft Excel. The goal is to clean the dataset, perform analysis, and build an interactive dashboard to generate business insights.

---

## 🧰 Tools Used
- Microsoft Excel  
- Data Cleaning  
- Pivot Tables  
- Charts & Graphs  
- Dashboard Design  

---

## 📊 Dataset Details
The dataset contains:
- Order ID  
- Customer ID  
- Product Category  
- Sales Amount  
- Shipping Details  
- Order Status  

---

## 📈 Key Analysis & Insights
- Monthly sales trends  
- Top-performing categories  
- Customer purchase behavior  
- Regional sales distribution  
- Order status analysis  

---

## 🎯 Features of Dashboard
- Interactive filters (Slicers)  
- Dynamic charts  
- KPI tracking  
- Easy-to-understand visuals  

---

## 📂 Files Included
- `Vrinda Store Data Analysis.xlsx` → Excel dashboard & dataset  

---

## 🚀 Project Goal
To demonstrate data cleaning, analysis, and visualization skills using Excel for business decision-making.
